# Malta: The Stone Crown

A browser-based, historically inspired open-world stealth adventure set in Malta in 1565.

- Explore fortified districts and harbour streets
- Sneak across limestone rooftops
- Fight with sword and dagger
- Evade patrols and complete the Governor’s plot mission
- No external assets or dependencies

Open `index.html` in a modern browser, or serve this directory with any static web server.
